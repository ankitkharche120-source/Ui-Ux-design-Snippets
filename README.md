# 🚀 Snippets – UI/UX Design

A modern social media application UI focused on meaningful engagement, clean design, and categorized content consumption.

---

## 🎯 Overview

Snippets is a UI/UX concept designed to improve how users interact with social media by reducing clutter and promoting purposeful content browsing.

---

## ✨ Key Features

- 📚 Smart Categorized Feed (Study, Tech, Life, Fun)
- 👤 Clean & Minimal User Profiles
- 🔍 Smart Search System
- ❤️ Meaningful Engagement Design
- 🎥 Reels / Content Viewing UI
- 🛍️ Integrated Shop UI

---

## 📱 Screens Included

- Splash Screen
- Login & Register
- Home Feed
- Search
- Reels
- Profile
- Shop
- Product Detail
- Comments
